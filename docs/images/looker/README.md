# Looker Studio Dashboard Screenshots Directory

Place your exported Looker Studio dashboard screenshots (PNG, JPG, or WebP) here.

### Recommended Naming Convention:
1. `sheet1_executive_overview.png` — Sheet 1: Executive Overview (KPIs, System Health, SLA)
2. `sheet2_performance_latency.png` — Sheet 2: System Performance & Latency (P50/P90/P99 Trends)
3. `sheet3_error_analysis.png` — Sheet 3: Error Analysis & Reliability (4xx vs 5xx Breakdown)
4. `sheet4_infrastructure_health.png` — Sheet 4: Infrastructure & Multi-Compute Resource Usage
5. `sheet5_cost_optimization.png` — Sheet 5: Cost Optimization & FinOps Recommendations
6. `sheet6_log_explorer.png` — Sheet 6: Developer Deep Dive & Distributed Log Explorer

Once you save your screenshots with these names in this directory, they will immediately render in the [README.md](../../README.md#📊-looker-studio-dashboard-showcase) showcase section!
